# Kiranlata website

Static catalogue website for Kiranlata, designed to be hosted on GitHub Pages and connected to a custom `.com` domain.

## Local preview

From this folder, run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000` in a browser.

## Content checklist

Before launch, replace the sample text and add web-ready product photographs in `assets/images/products/`.

- Logo and brand colours
- Saree names, fabrics, descriptions, prices, and photos
- About Kiranlata copy
- WhatsApp number and social links
- Shipping, returns, and privacy policy text

## Publishing

The site is compatible with GitHub Pages. Add the final custom domain to the `CNAME` file only after purchasing it and configuring it in GitHub Pages.
